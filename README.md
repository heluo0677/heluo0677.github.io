# 🇬🇧 English Version

## What is 34 Coins?

34 Coins is a **local-first time management and productivity web app**.

A day from **06:00 to 23:00** is divided into 34 time coins, with each coin representing 30 minutes.

You can record your actual time, classify it, review your day, analyze long-term patterns, and turn productive time into rewards.

## Features

* 🪙 34 Coins time tracking
* 📋 Daily planning
* 📝 Daily review
* 📊 Weekly / monthly / yearly analytics
* 📈 Trend analysis
* 🧠 Automated time diagnostics
* 💰 Coin wallet and rewards
* 🛍️ Coin shop
* 🔥 Streaks
* 💾 IndexedDB local storage
* 📦 JSON import / export
* 🔐 No account required

## Privacy

34 Coins follows a **local-first architecture**.

Your time records are stored locally in your own browser by default.
No account is required, and other visitors cannot see your personal records.

Regular JSON backups are recommended.

## Technology

HTML · CSS · JavaScript · IndexedDB · GitHub Pages
